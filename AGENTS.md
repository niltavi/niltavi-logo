# Repository guidance

Before proposing or making changes, load the [Niltavi project Skill](.agents/skills/niltavi-project/SKILL.md). Follow it to read the current [Niltavi Rules](https://github.com/niltavi/niltavi-rules#readme), [Niltavi Skills](https://github.com/niltavi/niltavi-skills#readme), and [Niltavi UI](https://github.com/niltavi/niltavi-ui#readme), in that order. Apply the shared rules when proposing, implementing, and verifying changes.

Use the [asset catalog](ASSETS.md) to choose the published variant. Keep existing asset paths and preserve the original colors and aspect ratios when reusing the wordmarks. For a new variant, keep the original files available for existing links.

After an edit, check the rendered README, the catalog links, and the light and dark wordmark sources.
